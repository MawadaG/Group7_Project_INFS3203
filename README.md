# Smart Task Manager

Smart Task Manager is a web application that helps users organize their work by creating tasks, assigning deadlines, grouping tasks into projects, and tracking progress through a dashboard.

The application includes an AI-powered feature that can break large tasks into smaller, actionable subtasks to help users plan their work more effectively.

Features

    -Create, update, and delete tasks
    -Assign deadlines and track task status
    -Organize tasks into projects
    -Dashboard overview of tasks and progress
    -AI-powered subtask generation

Setup Instructions (Run Locally)

    To run the application locally:
    
    Clone the repository:
    
      git clone https://github.com/MawadaG/Group7_Project_INFS3203
      cd Group7_Project_INFS3203
        
    Install the required dependencies:
    
      cd backend
      pip install -r requirements.txt
    
    Run the backend server:
    
      python app.py
    
    Open your browser and go to:
    
      http://localhost:5000
